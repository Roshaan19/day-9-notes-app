# Day 9 - Notes App

## Overview

This project is part of my 30-Day Full Stack Development Journey.

The goal of this project was to build a responsive Notes App using HTML5, CSS3, and JavaScript. Users can create, edit, delete, and search notes. All notes are saved using the browser's Local Storage, allowing data to persist even after refreshing the page.

---

## Features

- Add Notes
- Edit Notes
- Delete Notes
- Search Notes
- Local Storage Support
- Notes Counter
- Responsive Design
- Clean User Interface

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Start creating and managing your notes.
